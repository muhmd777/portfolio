My personal portfolio website: cybersecurity, penetration testing, and web development.

## About me
Computer Science and AI graduate from MTI University, focused on web security and penetration testing. I also build web applications with React and Next.js.

- React 19 + TypeScript
- TanStack Start (Router + Query)
- Tailwind CSS 4
- Vite, with Cloudflare deployment

## Run it locally

npm run dev

Then open the local address shown in your terminal.
